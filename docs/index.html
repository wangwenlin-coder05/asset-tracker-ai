Core Model

核心算法：T+1 有效止盈模型

避免「同一日冲高回落」的虚假止盈 —— 只把次日盘中仍能守住涨幅的推荐，计为有效业绩。

STEP 01

D0 推荐日

收盘涨幅 > 阈值（默认 5%，可选 10% / 20%）

STEP 02

D1 次日开盘

校验开盘价是否仍在阈值之上，规避未来函数

RESULT

✅ 有效止盈

次日开盘仍 ≥ 阈值，计为有效业绩

FILTERED

❌ 浮盈（无效）

冲高回落不计数，支持按推荐源排名投资人表现

Quant Subsystem

自然语言驱动的量化回测闭环

「回测茅台，止盈 5%，止损 5%」→ 自动同步行情 → 构建策略 → 事件驱动回测 → 生成报告。

AI AgentLLM Function Calling 编排 同步 → 回测 → 报告 多步工具链；内置确定性规则双路径回退，无 Key 也能端到端跑通。
事件驱动回测引擎逐 K 线撮合、T+1 次日开盘成交、显式规避未来函数；numpy 向量化计算最大回撤 / 夏普。
参数网格寻优多标的 × 参数组合笛卡尔积扫描，一键输出最优 止盈 / 止损 / 移动止盈 / 持仓 配置。
自定义策略工作室AI 生成策略代码、静态校验、冒烟测试、版本留存与一键回滚（v1.1.0 新增）。
数据链路腾讯 / baostock 双源增量同步、自动识别交易所前缀、指数退避重试，落库 SQLite。

Get Started

本地部署 · 数据不出内网

需要 Node.js 20+ 与 MySQL 8；量化子系统另需 Python 3.10+。

# 获取源码
git clone https://github.com/wangwenlin-coder05/asset-tracker-ai.git

# —— 主应用（Node + MySQL）——
npm install
cp .env.example .env      # 配置数据库等
npm start
cd frontend && npm install && npm run dev   # http://localhost:5273

# —— 量化服务（Python）——
cd quant
python -m venv .venv
.venv\Scripts\activate    # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn quant.api:app --host 127.0.0.1 --port 8000
打开仓库 量化子系统文档
